# EVGuardian AI

## Edge AI-Based Battery Health Monitoring and Remaining Useful Life Prediction for Electric Vehicles

EVGuardian AI is an intelligent battery health monitoring and predictive maintenance system designed for Electric Vehicles.

The system combines Machine Learning, IoT, Edge AI, and real-time battery monitoring to estimate the **State of Health (SOH)** and **Remaining Useful Life (RUL)** of lithium-ion batteries.

## Problem Statement

Lithium-ion batteries used in Electric Vehicles gradually degrade due to repeated charging and discharging cycles, temperature variations, and operating conditions.

Conventional battery monitoring systems mainly monitor parameters such as voltage, current, temperature, and State of Charge. EVGuardian AI aims to go beyond basic monitoring by using Machine Learning to predict battery degradation and estimate its remaining useful life.

## Objectives

- Monitor battery voltage, current, and temperature in real time.
- Predict Battery State of Health (SOH).
- Predict Remaining Useful Life (RUL).
- Provide predictive maintenance alerts.
- Enable remote battery monitoring using IoT and cloud technology.
- Implement Edge AI-based battery health prediction using Raspberry Pi.

## Proposed System

The proposed system uses sensors to collect real-time battery parameters such as voltage, current, and temperature. A Raspberry Pi acts as the main processing and edge computing unit.

A Machine Learning model trained using historical lithium-ion battery degradation data is used to estimate SOH and predict RUL.

The prediction results and sensor data are transmitted to the cloud for storage, remote monitoring, dashboard visualization, and maintenance alerts.
